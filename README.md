## 📌 Project Overview

This project analyzes Netflix content across different countries to identify the leading content-producing countries using Python, Pandas, Plotly, and Streamlit.

**Internship:** Auspify Technologies  
**Domain:** Data Analysis Using Python

## 🎯 Objective

Analyze the distribution of Netflix titles across countries and identify the leading content-producing countries.

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## 🔄 Project Workflow

1. Extract and clean country information.
2. Split multiple countries listed in a single record.
3. Calculate title counts by country.
4. Rank the top countries.
5. Visualize country-wise content distribution and derive insights.

## ✨ Dashboard Features

- Country and title statistics
- Top 10 countries chart
- Country selection filter
- Movie vs TV Show comparison
- Country-wise summary table
- CSV download

## ▶️ How to Run

Install the dependencies:

```bash
pip install pandas streamlit plotly
```

Run the dashboard:

```bash
python -m streamlit run app.py
```
